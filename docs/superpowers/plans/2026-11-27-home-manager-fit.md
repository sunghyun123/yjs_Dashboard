## 1. 게이트 1 결정 (2026-11-27)

**2안 + 3안.** 근거(조성현): 접힘 상태에서 다 보이는 게 우선이라서.

- 1안(테두리 드래그로 크기 조절) 기각 — 전자칠판은 터치라 얇은 경계를 잡기 어렵고, 기기마다 화면이 달라지며, 넘치는 문제를 사람이 매번 손으로 풀게 만든다.
- 2안: 아래 표 칸을 고정 비율(54%)에서 **내용 높이**로. 접히면 줄고 위 칸이 커진다. 펼치면 상한(60%)까지만 커지고 표 본문이 안에서 스크롤.
- 3안: 담당자 칸 압축 — 이름을 왼쪽 열, 시공·정산 막대 두 줄을 오른쪽에 붙인다(칸 높이 99 → 67~71px).
- 받아들인 대가: **펼친 동안**엔 위 칸이 줄어 담당자 목록에 다시 스크롤이 생긴다(PR #56에서 46/54로 되돌린 이유와 같은 상황, 단 상한이 있음). 접힘 우선이라 수용.

## 3. 구현 (web/home.html CSS만, home.js는 안 건드림)

1. `.home-right` `grid-template-rows: minmax(0, 46fr) minmax(0, 54fr)` → **`minmax(0, 1fr) fit-content(60%)`**.
   - ⚠ 실측에서 확인한 함정 둘:
     - `auto` + `.home-table-slot { max-height: 60% }`는 **안 된다** — 퍼센트 max-height가 auto 트랙 높이를 기준으로 풀려 표 칸이 201px로 잘림(그래프만 남고 표 본문 0px).
     - 그래서 상한은 아이템이 아니라 **트랙**에 건다: `fit-content(60%)` = min(내용 높이, 60%). 이 값으로 접힘 335 / 펼침 496(1600) 확인.
   - 주석의 "아래 칸이 더 큰 이유" 문구와 `.home-table-slot` 주석을 새 동작(접히면 내용 높이, 펼치면 60%까지)으로 고친다.
2. `.mgr-row`를 세로 flex → **2열 grid**: `grid-template-columns: 96px 1fr; grid-template-rows: auto auto; column-gap: 10px; row-gap: 4px; padding: 6px 12px;` + `.mgr-name { grid-row: 1 / span 2; white-space: nowrap; }`.
   - 이름 열 96px: 76px에선 "담당 미지정"이 두 줄로 꺾임(실측). 96px + nowrap이면 한 줄.
   - `flex: 1 0 auto`(칸이 남는 높이를 나눠 갖기)는 그대로 둔다 — 1920에서 칸이 107px로 늘어 아래 여백이 안 남는다.
   - 정산 막대가 없는 화면(`showSettle=false`)에서도 2행 grid가 빈 둘째 행을 가질 뿐 깨지지 않는지 확인.
3. `@media (max-width: 1200px), (max-height: 720px)` 블록(`.home-right { grid-template-rows: auto auto; }`)은 그대로 — 좁은 화면은 원래 페이지 스크롤.
4. `home.html`만 바뀌므로 `home.js?v=`는 안 올린다(html이 새 것이면 CSS도 새 것 — CSS는 home.html `<style>` 안).

## 4. 확인 (구현 세션)

- 1600×900·1920×1080: 접힘에서 담당자 5칸 스크롤 없음, 표 2줄 + 그래프 150px 그대로.
- 시공·정산 각각 펼침: 표 칸이 60%에서 멈추고 표 본문만 스크롤, 그래프 바닥 고정 유지.
- 접기 → 다시 위 칸이 커짐(60초 갱신 뒤에도).
- 1200px 이하 좁은 화면 깨짐 없음.
- **11-18 교훈:** 칸 모양(담당자 칸 2열)이 눈에 보이게 바뀐다 → 머지 전 사장님께 시안 캡처를 보여 드릴지는 조성현 판단(지우는 칸은 없음).

## 5. 구현 결과 (2026-11-27 구현 세션)

운영 홈에 새 CSS를 내 탭에서만 주입해 실측(실데이터 5칸).

| 화면 | 상태 | 담당자 목록 | 칸 | 표 칸 | 스크롤 |
| --- | --- | --- | --- | --- | --- |
| 1600×900 | 접힘 | 388 | 71 | 335 | 없음 |

- 다시 접으면 원래 값으로 복귀. 1100·768px(iframe) 가로 스크롤 없음.

- 60초 자동 갱신 뒤 모습은 미확인(접기/펼치기 재렌더로 대신 확인).

### 백로그
- **계획외 실적 줄이 생기면 1600×900에서 27px 넘침**(예측 약 10px, 가짜 줄 주입 실측 415/388). 넘치는 27px이 바로 그 줄(약 30px)이라 **새로 생긴 줄만 거의 통째로 가려지고**, 표·그래프는 ERP 합계라 그대로 → 흔적은 목록의 얇은 스크롤바뿐. 10-12 "계획외 한 줄을 남긴다"가 막으려던 사고가 화면 높이로 재현되는 형태. 지금 데이터엔 안 나와 범위 밖(조성현 결정).
